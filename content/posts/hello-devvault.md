# DevVault 建站开篇

终于搭好了个人技术站点，用来存放技术随笔和项目作品。

## 技术栈

- 静态站点生成器：Hugo Extended
- 主题：PaperMod
- 托管：Gitee Pages（国内访问），后续镜像 GitHub Pages
- 仓库：[goccoder/dev-vault](https://gitee.com/goccoder/dev-vault)

## 为什么用 Hugo

1. 单二进制，本地预览快
2. 原生支持 Markdown 写作
3. 生成纯静态文件，任何静态托管都能跑
