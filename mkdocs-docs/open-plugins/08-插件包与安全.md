# 08 · 插件包与安全：Zip 分发、AES 签名与 MD5 完整性

插件以"包"的形式分发——一个 `*.zip` 内含插件库与签名清单。本章拆解 `plugins_manager/detail/package.{hxx,cpp}`：打包格式、`signature.bin` 的 AES 加解密、逐文件 MD5 校验、以及 Zip/Unzip 实现。

## 8.1 插件包是什么

一个合法插件包 `xxx.zip` 大致包含：

```
xxx.zip
├── signature.bin            # 包信息（含文件清单），AES 加密
├── plugin_<name>.<dll|so|dylib>   # 插件动态库
└── ...其他资源（XRC/翻译/数据）
```

包信息在内存里是一个 `Package` 结构体（`package.hxx`），用 iguana 反射声明：

```cpp
REFLECTION(Package, version, build_time, name, files)

struct Package {
  int64_t version;    ///< 插件包版本号（时间戳语义）
  int64_t build_time; ///< 编译时间
  std::string name;   ///< 插件包名
  map_type files;     ///< 插件包文件列表（文件名 -> MD5 十六进制）
};
using map_type = std::map<std::string, std::string, std::less<>>;
```

- `files` 记录包内每个插件的文件名及其 MD5——这正是**完整性校验的依据**；
- `version` 在 `PluginsPackageInfo` 中注释为"时间戳格式"。

## 8.2 打包流程（签名 + 加密）

打包侧把 `Package` 序列化成 JSON、再用 AES 加密成 `signature.bin`（`SaveInfo`）：

```cpp
bool SaveInfo(const Package &info, std::vector<char> &buffer) {
  iguana::string_stream ss;
  iguana::json::to_json(ss, info);              // 结构体 -> JSON
  auto json_str = ss.str();
  auto encrypted = ::aesEncrypt(json_str, AES_PASSWORD); // AES 加密
  buffer.assign(encrypted.begin(), encrypted.end());
  return true;
}
```

配合 `Zip(dir, zip_path)` 把整个目录打成 zip（`wxZipOutputStream`），于是形成 `xxx.zip`（含 `signature.bin` 与插件库）。

## 8.3 校验流程：CheckPackage_

运行期加载前，`CheckPackage_` 对每个包做"**签名解密 → 解析清单 → 逐文件 MD5 比对**"三步：

```cpp
static bool CheckPackage_(const std::string &plugins_) {
  std::vector<char> buffer;
  if (!::LoadSignture(plugins_.c_str(), buffer)) return false; // ① 读 signature.bin
  if (!::Decode(buffer)) return false;                          // ② AES 解密
  if (buffer.empty()) return false;

  Package p;
  if (!::ParseInfo(buffer, &p)) return false;                   // ③ JSON -> Package

  map_type md5s;
  if (!::LoadMD5(plugins_.c_str(), md5s)) return false;         // ④ 计算包内文件 MD5

  for (auto [key, value] : md5s) {                              // ⑤ 逐文件比对
    if (auto itr = p.files.find(key); itr == p.files.end()) {
      return false;                                             //   清单里没有该文件
    } else if (itr->second != value) {
      return false;                                             //   MD5 不一致
    }
  }
  return true;
}
```

各步骤细节：

**① 读取签名文件（LoadSignture）**——打开 zip 流，找到名为 `signature.bin` 的条目并读出：

```cpp
while ((entry = zipStream.GetNextEntry()) != nullptr) {
  if (entry->GetName() == "signature.bin") {
    size_t signSize = entry->GetSize();
    if (signSize == 0) return false;
    buffer.resize(signSize + 1);
    zipStream.Read(buffer.data(), signSize);
    return true;
  }
}
return false;
```

**② AES 解密（Decode）**——用包管理器的密码解开：

```cpp
bool Decode(std::vector<char> &buffer) {
  auto str = ::aesDecrypt(std::string(buffer.data(), buffer.size()), AES_PASSWORD);
  if (str.empty()) return false;
  buffer.assign(str.begin(), str.end());
  return true;
}
```

**③ 解析清单（ParseInfo）**——iguana 反序列化回 `Package`：

```cpp
bool ParseInfo(const std::vector<char> &buffer, Package *info) {
  iguana::json::reader_t reader(buffer.data(), buffer.size());
  iguana::json::read_json(reader, *info);
  return true;
}
```

**④ 计算文件 MD5（LoadMD5）**——遍历 zip 里所有"是插件"的条目，逐个算 MD5 并以"文件名 -> 十六进制 MD5"填入 `md5s`：

```cpp
if (auto filename = entry->GetName(); ::IsPlugins(entry->GetName())) {
  cMd5 md5sum;
  size_t totalRead = entry->GetSize();
  while (totalRead > 0) {
    size_t toRead = std::min(buffer.size(), totalRead);
    size_t read = zipStream.Read(buffer.data(), toRead).LastRead();
    totalRead -= read;
    md5sum.write(buffer.data(), read);
  }
  md5sum.sum(buffer.data() + 32);
  ::bin2hex(buffer.data(), buffer.data() + 32, MD5LEN);
  md5s.try_emplace(filename.utf8_string(), buffer);
}
return !md5s.empty();
```

`IsPlugins` 判定"是插件文件"：

```cpp
bool IsPlugins(const wxString &filename) {
  auto fname = wxFileName::FileName(filename).GetFullName();
  return fname.StartsWith(PLUGIN_PREFIX) && fname.Lower().EndsWith(PLUGIN_EXT);
}
```

即以 **`PLUGIN_PREFIX` 开头且以平台扩展名结尾**——macOS/Linux 前缀为 `libplugin_`，仅 Windows 为 `plugin_`（`PLUGIN_PREFIX` / `PLUGIN_EXT` 由平台宏决定，见 `plaform.hpp`）。

## 8.4 AES 实现：AES-256-CBC + PBKDF2

`signature.bin` 的加密用的是 `utility/encrypt/aes.{hxx,cpp}`，一个标准但值得记录的实现：

```cpp
#define PBKDF2_ITERATIONS 10000
#define SALT_SIZE 16
#define IV_SIZE 16
// 输出格式：盐(16) + IV(16) + 密文
```

- **算法**：`EVP_aes_256_cbc()`（AES-256-CBC），启用 PKCS#7 填充；
- **密钥派生**：`PKCS5_PBKDF2_HMAC_SHA1(password, salt, 10000, key=32)`——口令 + 随机盐 + 1 万次迭代；
- **随机性**：盐与 IV 都由 `RAND_bytes` 生成；
- **输出格式**：`盐(16) + IV(16) + 密文`，解密时从头部切出盐和 IV 再派生密钥、解密；
- **密码来源**：`plugins_manager/CMakeLists.txt` 里 `set(AES_PASSWORD "anycubic.com" CACHE STRING ...)`，作为 `AES_PASSWORD` 宏编译进 manager。

```cpp
std::string aesEncrypt(const std::string_view &plaintext,
                       const std::string_view &password) {
  unsigned char salt[SALT_SIZE], iv[IV_SIZE], key[32];
  if (!generate_salt(salt) || RAND_bytes(iv, IV_SIZE) != 1) break;
  if (!derive_key(password, salt, key, sizeof(key))) break;
  EVP_EncryptInit_ex(ctx, EVP_aes_256_cbc(), nullptr, key, iv);
  EVP_CIPHER_CTX_set_padding(ctx, 1);
  ciphertext.resize(SALT_SIZE + IV_SIZE + plaintext.size() + block_size);
  memcpy(buffer, salt, SALT_SIZE);
  memcpy(buffer + SALT_SIZE, iv, IV_SIZE);
  EVP_EncryptUpdate(ctx, buffer + SALT_SIZE + IV_SIZE, &len, plaintext.data(), plaintext.size());
  EVP_EncryptFinal_ex(ctx, buffer + SALT_SIZE + IV_SIZE + len, &len);
  ciphertext.resize(SALT_SIZE + IV_SIZE + total_len);
}
```

## 8.5 校验失败的语义：跳过而非中断

回到 manager 层（第 4 章已见），`CheckPackage()` 对每个 zip 校验，失败只 `LOG_WARN` 跳过：

```cpp
if (!CheckPackage_(zipFile.GetFullPath().utf8_string())) {
  LOG_WARN("check package failed:{}", filename);
  continue;                    // 校验失败 → 不加入 plugin_packages_
}
plugin_packages_.push_back(filename);
```

设计取舍很清楚：

- **完整性校验通过** → 该包进入加载流程；
- **签名解密失败 / JSON 解析失败 / 某文件 MD5 不符 / 清单不含某文件** → 整包跳过，并记录警告日志；
- **跳过不终止**：其他正常包照常加载。

> 安全模型归纳：**AES 加密 `signature.bin` 用于防篡改与"授权"标记，逐文件 MD5 用于完整性**。其强度取决于 `AES_PASSWORD`（默认 "anycubic.com"，编译期可配）是否足够私密——属于"混淆 + 完整性校验"级别的保护，而非不可逆的强加密签名（仓库也未见 RSA 用于包签名，RSA 工具在 `utility/encrypt/rsa.*`，用于其它加密配置场景）。

## 8.6 解压与插件识别

加载时 `UnzipAll` 把每个合法包解压到临时目录：

```cpp
bool UnzipAll(const std::vector<wxString> &plugins_packages,
              const std::string &tmp_dir) {
#ifdef NDEBUG
  if (dir.DirExists()) dir.Rmdir(wxPATH_RMDIR_RECURSIVE);  // Release 先清空临时目录
  dir.Mkdir(...);
#endif
  for (auto package : plugins_packages) {
    if (!Unzip(package.utf8_string(), tmp_dir, false)) return false;
  }
  return true;
}
```

`Unzip` 只解压"是插件"的文件（`IsPlugins` 过滤），统一路径分隔符，并带流错误检查：

```cpp

```

`GetPluginName` 从文件名解析插件名（去掉 `PLUGIN_PREFIX` 前缀，Debug 下再去掉 'd' 后缀）：

```cpp
wxString GetPluginName(const wxString &filename) {
  auto name = wxFileName::FileName(filename).GetName();
  name.Replace(PLUGIN_PREFIX, wxASCII_STR(""));
#ifndef NDEBUG
  name = name.RemoveLast(1);   // 移除 'd' 标记（Debug 库名形如 plugin_xxxd）
#endif
  return name;
}
```

## 本章要点

- 插件包是 zip，内含 `signature.bin`（AES 加密的包清单）与插件库；
- 包清单 `Package` 含版本、构建时间、名字、逐文件 MD5；用 iguana JSON 序列化；
- 校验三步：读签名 → AES 解密 → JSON 解析 → 逐文件 MD5 比对；
- AES 为 AES-256-CBC + PBKDF2(SHA1,10000)，输出 `盐+IV+密文`，密码 `AES_PASSWORD` 编译期可配；
- 校验失败的包被跳过、不中断加载；`Unzip` 只解压 `plugin_*` 文件并带流错误检查。
